# Brand assets

Node and credential icons are bundled locally from the existing AceDataCloud Studio/service catalog. No icon is fetched at node runtime.

- Source: https://cdn.acedata.cloud/e40fccc727.png
- Catalog service: Fish Audio
- Original SHA-256: aa20f99ea4423d4fd10976b62a6927bb96c9b9a5ab97a6ad5ba9d33993f28a10
- Preparation: aspect-preserving resize onto a white 256×256 tile, exported as PNG; the tile is readable in both light and dark n8n themes.

The service mark identifies the integration. This package is maintained by AceDataCloud and does not claim to be an official package from the model developer.

## Fish Audio vector artwork

The Studio Fish favicon is only 32×32. This package uses the matching high-resolution Fish Audio mark from the MIT-licensed Lobe Icons project for crisp node rendering. Source: https://github.com/lobehub/lobe-icons/blob/master/packages/static-png/light/fishaudio.png. The source SVG and required copyright/license notice are preserved here in fishaudio.svg and lobe-icons-LICENSE.
